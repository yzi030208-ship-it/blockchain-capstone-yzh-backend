# 实验原始截图

截图命名、责任人及报告位置见 [`docs/evidence-capture-guide.md`](../docs/evidence-capture-guide.md)。在有真实图片时放入以下目录：

- `prep/`：上链前代币与账户准备，使用 `4A-PREP` 编号。
- `4A/`：老师报告路线 A 的 `4A-1` 至 `4A-8` 及补图 `4A-S1/S2`。
- `4C/`：重入挑战 `4C-1` 至 `4C-3`。
- `timeline/`：本组时间线加分图 `T-1` 至 `T-3`。

原始截图须清楚、可读；入库前检查画面没有私钥、助记词、访问令牌或终端输入密钥的过程。没有实际发生的交易不得用示意图代替。
